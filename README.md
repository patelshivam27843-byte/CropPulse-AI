# CropPulse AI — SIH 26131

Single-package Flask prototype with:
- GPS location capture
- Open-Meteo weather + estimated soil moisture
- 40 India-relevant crops with search and condition-based ranking
- photo upload + image quality checks
- field/weather risk score and severity
- curated non-prescriptive disease/pest management guidance
- SQLite history
- Hindi/English localization hook
- AI-ready CV architecture without fake disease confidence

Important: pixel-level disease detection is NOT falsely claimed. Connect a trained/validated CV model before showing disease confidence.
